# 기능 명세

두 개발자 모두 기존 .specify 설정을 이용해 Spec Kit으로 기능 명세·계획·작업을 관리한다. 설정·템플릿은 임의로 재생성하지 않는다.

- 제품 범위: IDEA.md
- 제공 형태: MCP 서비스. Hermes는 개발·시연 클라이언트이며 별도 제품 화면을 개발하지 않는다.
- MCP 연결 계층·백엔드의 REST 계약: API_SPEC.md와 Docs/api/examples.json
- 서비스 Agent 역할 초안: agent_specs/

새로운 기능 명세가 공통 API나 MVP 범위를 바꾸면 먼저 공동 합의하고 기준 문서를 갱신한다. 이전 이동 영구 저장·출발/도착 버튼·알림 요구는 현재 MCP MVP에 적용하지 않는다. 기존 작업 ID는 이력을 위해 보존하되 비적용 항목을 구현 지시로 읽지 않는다.
