# 구현 계획: 이동 입력·조건 확인·출발 시각 계산

> 2026-09-14: 서비스 제공 형태는 MCP로 확정됐다. Hermes는 개발·시연용 클라이언트다. 기존 REST 스키마는 유지하며, 제품 전제의 정정은 구현·테스트 완료를 의미하지 않는다.

## 요약

사용자 자연어 이동 요청에서 장소·시각·도착 여유·이동수단을 구조화하고, 부족한 조건만 최대 3개 질문한 뒤, 실제 서울 교통 데이터로 권장 출발시각과 계산 근거를 제공하는MVP 핵심 흐름을 구현한다. 핵심은 **AI는 구조화·질문·설명만 담당하고, 시간 계산·경로 유효성·상태 전이·권한 검증은 검증 가능한 코드로 처리**하는 분리다.

## 기술 맥락

**언어/버전**: Python 3.11 백엔드를 유지한다. 본인은 MCP 연결 계층을 구현하고 Hermes를 개발·시연 클라이언트로 사용한다.

**주요 의존성**: FastAPI(백엔드), Docker(컨테이너 패키징), GCP Cloud Run(배포 환경). AI는 서버 내부 호출이며 Solar Pro4 등 실행 모델·호출 경로는 미정. 교통 데이터는 서울시 공공데이터 포털·공공데이터 포털 API(발급된 키), 실제 응답·지원 범위 검증 필요.

**저장소**: 요청별 계산 백엔드와 현재 대화의 확인·선택 문맥을 구분한다. UserData DB·영구 이동 이력은 필수가 아니며 상태 소유권·수명은 구현 전에 합의한다.

**테스트**: 백엔드는 pytest 기반 단위·통합 테스트. 시간대(Asia/Seoul), 자정 경계, 도착 여유, Buffer 중복 계산, 상태 전이, 사용자 고정 조건, 데이터 없음· 제공처 장애 구분을 자동화된 테스트 또는 재현 가능한 통합 검증으로 확인.

**대상 플랫폼**: 서비스는 MCP로 제공한다. Hermes + Solar Pro4에서 로컬 stdio MCP 연결을 우선 검증하고, 기존 HTTP 백엔드는 Cloud Run 배포 대상으로 유지한다.

**프로젝트 유형**: MCP 서비스 + FastAPI 계산 백엔드. 독립 사용자 클라이언트는 개발하지 않는다.

**성능 목표**: health/capabilities 3초, places 10초, interpret/plan/replan 25초(서버 처리 초안). MCP→백엔드 대기 제한 GET 15초, POST 30초.

**제약**: 대상 지역 서울, 시간대 Asia/Seoul만, 택시 미지원, MVP 재탐색은 사용자 요청 기반, 자동 재탐색·백그라운드 재계산·GPS 상시 추적·Calendar 동기화·개인화 학습·전국 교통·자체 지도/Turn-by-turn Navigation 제외.

**규모/범위**: 2명·4일 MVP. 핵심 흐름은 자연어 입력 → 조건 확인 → 실제 데이터 기반 출발시각·근거 표시. 막차와 재탐색은 검증된 지원 범위에서 확장.

### 소스 코드(저장소 루트 기준)

공통 인수인계 시점의 backend/는 폴더 골격이다. 로컬 작성 중 코드는 이번 공유에 포함하지 않으며, 재사용이 필요하면 별도 검토·합의 후 통합한다. MCP 연결 계층은 별도 담당자가 추가한다. mobile/·cli/는 과거 검토 보존 폴더이며 현재 개발 대상이 아니다. MCP 구현 위치·실행 진입점은 담당 명세에서 정한다.

```text
backend/
├── app/
│   ├── main.py          # FastAPI 진입점(구현·실행 상태 별도 확인)
│   ├── api/             # 라우트
│   ├── schemas/         # 요청·응답 스키마
│   ├── domain/          # 도메인 로직(시간 계산·상태·권한)
│   ├── integrations/    # 교통·장소·AI 어댑터
│   └── agents/          # MainAgent·SubAgent 실행 조율
├── tests/
│   ├── contract/        # 공개 JSON 계약 검증
│   ├── integration/     # 종단 간 흐름
│   └── unit/            # 도메인·계산·상태 전이
```

**구조 결정**: 본인은 MCP 도구·Hermes 확인/선택 흐름을, 친구는 백엔드 계약·계산·Agent·데이터 연동을 담당한다. 이 계획의 백엔드 작업은 유지하고 MCP 도구 스키마·오류 매핑·문맥 소유권의 상세 작업은 공동 명세로 보완한다.
