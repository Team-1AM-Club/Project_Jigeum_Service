## 1. 막차 귀가 마지노선 — `maginot-line`

### 문제 정의

늦은 시간에 귀가하는 대학생과 직장인은 “막차가 몇 시지?”를 확인한 뒤에도 버스·지하철 환승, 도보 시간, 막차 연결 여부를 다시 계산해야 합니다. 특히 주 1회 이상 야간 약속이나 과제를 마치고 귀가하는 사람은 지도 앱, 막차 정보, 택시 앱을 번갈아 보며 귀가 가능 여부와 출발 마지노선을 판단하는 불편을 겪습니다. 단일 노선의 막차시각만 알아서는 전체 귀가 경로가 실제로 연결되는지 알기 어렵고, 몇 분 늦으면 귀가 방법 자체가 달라질 수 있다는 문제가 있습니다.

### 문제 해결 방식

이 Skill은 “막차가 언제인가?”가 아니라 “집에 가려면 언제까지 출발해야 하는가?”를 답합니다. 현재 시각·출발지·귀가 목적지·택시 허용 여부를 확인한 뒤, 권장 최종 출발시각과 이론상 가능한 최후 시각을 구분해 안내합니다. 기존 지도 서비스가 경로와 ETA를 보여주는 데 집중한다면, 이 Skill은 환승과 도보 여유를 포함한 **귀가 Deadline 판단**에 집중합니다. 확인되지 않은 막차·운행·요금 정보는 임의로 만들지 않고, 필요한 정보를 추가 확인하도록 안내합니다.

### 스킬 동작 방식

1. 사용자의 귀가 요청에서 출발지와 목적지를 파악합니다.
2. 현재 시각, 정확한 목적지, 택시 허용 여부 등 부족한 정보를 한 번에 최대 3개까지 질문합니다.
3. 확인된 경로·막차 정보가 있으면 환승과 도보 여유를 고려해 권장 출발시각과 최후 시각을 구분합니다.
4. 대중교통 이용이 어려우면 택시 허용 조건에 맞는 대안을 안내합니다.
5. 교통 정보가 확인되지 않았으면 확정적인 시간을 제시하지 않고, 확인해야 할 정보와 다음 행동을 안내합니다.

## 2. 언제 나가야 해? — `leave-by`

### 문제 정의

약속, 수업, 출근처럼 특정 시각까지 도착해야 하는 일정이 있을 때 사용자는 목적지와 약속시각은 알고 있어도 “그래서 몇 시에 나가야 하지?”를 매번 다시 계산해야 합니다. 일정이 있는 날마다 지도 앱으로 이동시간을 확인하고, 환승·도보·개인적인 도착 여유까지 더해야 합니다. 특히 늦지 않기 위해 5~10분 일찍 도착하고 싶은 대학생·직장인에게는 단순 경로 검색만으로 실제 출발 판단을 내리기 어렵다는 문제가 있습니다.

### 문제 해결 방식

이 Skill은 자연어 일정 입력을 출발시각 결정으로 바꿉니다. 목적지, Deadline, 출발지, 도착 여유시간을 구조화하고, Deadline에서 도착 여유를 뺀 목표 도착시각을 먼저 정합니다. 이후 확인된 이동시간과 Safety Buffer를 반영해 권장 출발시각을 제시합니다. 기존 지도 앱이 “어떻게 갈지”를 알려준다면, 이 Skill은 사용자가 가장 궁금해하는 **“언제 움직여야 하는지”**를 결론으로 안내하는 것이 차별점입니다.

### 스킬 동작 방식

1. 사용자의 자연어에서 목적지, 도착시각, 출발지, 도착 여유시간을 추출합니다.
2. 장소나 오전·오후가 모호하면 임의로 확정하지 않고 최대 3개까지 확인 질문을 합니다.
3. Deadline과 도착 여유시간을 바탕으로 목표 도착시각을 계산합니다.
4. 확인된 이동시간과 도보·환승 여유를 반영해 권장 출발시각을 안내합니다.
5. 이동시간 또는 경로가 확인되지 않으면 시간을 지어내지 않고, 지도 앱 경로 등 추가 확인이 필요한 정보를 요청합니다.
6. 이미 늦을 위험이 있으면 질책하지 않고 현재 가능한 대안과 위험을 알려줍니다.

## 3. 환승 놓쳤을 때 플랜 B — `plan-b-recovery`

### 문제 정의

사용자는 버스나 지하철 환승을 놓치면 기존 계획이 무너진 순간부터 다시 길찾기, 도착시간 계산, 택시 비용 판단을 모두 해야 합니다. 약속이나 수업 직전에는 시간이 부족해 여러 앱을 비교하기 어렵고, “대중교통을 계속 이용할지”, “택시로 전환할지”, “늦을 가능성을 미리 알려야 할지”를 빠르게 판단해야 합니다. 이동 중 계획이 깨지는 일은 빈번하지만, 일반 길찾기 서비스는 사용자가 스스로 새 경로를 탐색하고 선택해야 하는 부담이 남습니다.

### 문제 해결 방식

이 Skill은 환승 실패·경로 지연 상황에서 다음 행동을 결정하도록 돕습니다. 현재 시각·위치·목적지·Deadline·놓친 교통편·택시 허용 여부를 확인하고, 대중교통 유지, 택시 전환, Deadline 준수가 어려운 경우를 구분해 제시합니다. 정상 이동을 계속 안내하는 내비게이션이 아니라, **문제가 생긴 순간에만 개입하는 예외 대응 Skill**이라는 점이 차별점입니다. 확인되지 않은 교통편이나 도착시각은 단정하지 않고 위험도와 확인 필요 정보를 함께 보여줍니다.

### 스킬 동작 방식

1. 사용자의 메시지에서 놓친 교통편 또는 지연 상황을 파악합니다.
2. 현재 시각, 현재 위치, 목적지, Deadline, 택시 허용 여부 등 부족한 정보를 최대 3개까지 질문합니다.
3. 확인된 정보만으로 정시 가능, 지각 위험, 판단 불가 상태를 구분합니다.
4. 대중교통 유지와 택시 전환 등 가능한 선택지를 1~3개로 정리합니다.
5. 각 선택지의 장단점과 Deadline 위험을 설명하고, 사용자가 직접 선택하도록 합니다.
6. 지각 위험이 높을 때는 연락 등 보조 행동을 안내하되, 이를 이동 대안과 구분합니다.

## 제출 전 점검

- 제출하는 Skill 이름과 문서 제목이 일치하는지 확인한다.
- 실제 구현하지 않은 실시간 교통 데이터 조회, GPS 추적, Push 알림 기능은 포함하지 않는다.
- 확인되지 않은 정보는 생성하지 않는 안전 원칙을 각 Skill의 차별점으로 유지한다.
