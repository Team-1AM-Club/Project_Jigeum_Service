# RecoveryAgent

상태: 역할 명세. 실행 코드는 아직 없다.

- Skill: plan-b-recovery, route-risk-checker.
- 입력: 사용자 재탐색 요청, 현재 출발 기준점, 유지할 목적지·Deadline, 이전 계획 요약.
- 책임: 사용자 확인 후 코드 도구로 현재 조건의 경로를 재조회하고 이전 계획 대비 변화를 설명한다.
- 사용자가 고정한 조건을 임의 변경하지 않는다. 재탐색 실패 시 기존 기록을 지우지 않는다.
- 새 계획은 사용자 선택 후 적용한다. 자동 경로 이탈 감지·상시 재탐색·택시 최적화는 활성화하지 않는다.
- 출력: 새 계획과 비교 결과 또는 계약에 정의한 이용 불가·오류.
