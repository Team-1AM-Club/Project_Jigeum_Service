# MainAgent

상태: 역할 명세. 실행 코드는 아직 없다.

- 입력: 사용자 요청, 현재 이동 조건·계획, 사용자 확인 상태.
- 책임: 요청을 분류하고 필요한 SubAgent에 작업을 배정하며 결과를 취합한다.
- 입력이 불명확하면 TripIntakeAgent, 신규 계획이면 DeparturePlannerAgent, 계획 실패 후 재탐색이면 RecoveryAgent를 사용한다.
- 계산 전 사용자 조건 확인과 새 계획 적용 전 사용자 선택을 유지한다.
- 출력은 API_SPEC.md의 구조화 응답으로 검증한다. 모델이 시간·경로를 임의 생성하거나 실제 실행 전 조회·저장 성공을 주장하지 않는다.
- 실행 순서, 호출 횟수·제한시간·실패 시 반환 규칙은 구현 specs에서 정한다. 무제한 재귀 위임은 하지 않는다.
