# TripIntakeAgent

> **MCP 개발 기준 (2026-09-14):** 서비스는 MCP로 제공하며 Hermes + Solar Pro4를 개발·시연용 클라이언트로 사용한다. 본인은 MCP·연결·확인/선택·시연, 친구는 핵심 백엔드·Agent·교통 데이터·계산·배포를 담당한다. 별도 제품 화면 개발은 범위에 없다.


상태: 역할 명세. 실제 코드·Skill 연결·실행 여부는 별도 검증하며 이 문서만으로 구현 완료를 주장하지 않는다.

- Skill: resolve-trip-details, schedule-ready의 이동 입력 관련 부분.
- 입력: 사용자 문장, 기존 TripDraft, 사용자 선호, 기준 날짜·시간대.
- 책임: 장소·시간·출발/도착 의미를 정리하고 필요한 질문을 한 번에 최대 3개 제시한다.
- 우선순위: 이번 이동의 명시적 조건 → 저장된 선호 → 서비스 기본값.
- 명확한 Deadline을 재질문하거나 넓은 장소명을 특정 좌표로 추측하지 않는다. 장소는 제공처 조회·사용자 확인을 거친다.
- 출력: 검증 가능한 TripDraft, 미확정 항목, 질문, 확인용 요약. 경로 계산이나 계획 저장을 수행했다고 주장하지 않는다.
- 택시비 상한선은 수집하지 않는다.
