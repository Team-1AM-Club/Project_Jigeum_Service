# DeparturePlannerAgent

상태: 역할 명세. 실행 코드는 아직 없다.

- Skill: leave-by, maginot-line, route-risk-checker.
- 입력: 사용자가 확인한 이동 조건과 검증된 교통 데이터.
- 책임: 목적에 맞는 Skill을 사용해 계획 도구를 호출하고 계산 결과·위험·가정을 설명한다.
- 시간 계산, 경로 연결 유효성, 도보·대기·환승과 Safety Buffer 중복 방지는 코드 도구가 담당한다.
- 실시간 도착 정보만으로 미래 경로나 막차 환승이 검증된 것으로 취급하지 않는다.
- 막차는 확인된 운행일·방향·종착역·환승 범위에서만 안내한다. 미지원과 제공처 오류는 구분한다.
- 출력: API 계약에 맞는 계획 또는 확인 필요·이용 불가·오류. 출처와 데이터 기준시각을 유지한다.
