# Mobile scaffold

이 프로젝트의 앱 클라이언트 위치. 본인 담당이며 React Native + Expo를 사용할 예정이다.

월요일 멘토링에서 앱 서비스로 확정한 뒤 초기화한다. 현재 package.json이나 실행 가능한 Expo 앱은 없다. 앱 선택 시 스토어 등록 없이 Android APK 빌드·설치 흐름을 검증한다.

서버 호출은 API_SPEC.md를 따르고 개발 초기에는 Docs/api/examples.json의 가상 데이터를 사용한다. 앱에 모델·교통 API 비밀키나 DB 비밀번호를 넣지 않는다. 사용자 DB 저장은 인증·권한 계약 확정 후 연결한다.
